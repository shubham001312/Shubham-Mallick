IMURUN · v0.3.0 · MIT

Your code. Your machine.Your model.

IMURUN is ImuTechz’s local-first AI chat with its own inference engine. FISH, a C++ engine, runs GGUF models on your CPU; a Python server hosts sessions, tools and connectors; and the Liquid Paper UI opens in a native window or your browser. Windows, macOS and Linux — MIT licensed.

What IMURUN is made of

F.01

FISH, its own engine

A C++ inference engine that runs GGUF models on the CPU — the core of IMURUN, built by ImuTechz.

F.02

A Python server

Sessions, tools and connectors live in a local Python server that the UI talks to.

F.03

The Liquid Paper UI

A clean chat interface that opens in a native window or in your browser — your choice at launch.

F.04

Local-first

The model runs on your own machine, so the conversation stays there too.

F.05

Windows, macOS, Linux

One install on every desktop platform (Python 3.11–3.14).

F.06

Open source, MIT

Code, issues and history are public on GitHub — read it, fork it, contribute.

❯pip install imurun
OR NPX IMURUN · PYTHON 3.11–3.14

Install, launch, chat

01

Install

One command with pip. Python 3.11–3.14 on Windows, macOS or Linux.

pip install imurun
02

Launch

Run imurun — Liquid Paper opens in a native window, or pass --browser to use your browser.

imurun
03

Chat, locally

FISH runs a GGUF model on your CPU; choose one with --model. The conversation stays on your machine.

imurun --model …

Your machine.
Your model.

FISH runs the model on your own CPU, so your chats stay on your machine. The repository, the issues and the history are open: anyone can audit what changed, when, and why.
