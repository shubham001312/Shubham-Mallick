IMU CLI · IMURUN v0.1.10 · MIT · Open source

Your code. Your machine. Your model.

IMURUN is a local-first AI coding agent for the terminal. It installs, manages and runs large language models entirely on your own hardware — CPU or GPU — with no cloud dependency, no telemetry and no separate runtime to configure. Local models are the default, and everything IMURUN needs to run them ships with it.

Everything the agent can do

F.01

Models that fit your machine

Probes your hardware, recommends models that actually run well locally, then downloads them with live progress and verified checksums.

F.02

A real terminal TUI

A keyboard-first interface with a status line, mouse support and slash commands — built for the shell you already live in.

F.03

Agents with working modes

Switch the agent's prompt and toolset per job — researcher, refactorer, reviewer — or write your own in one file.

F.04

Skill library, routed

A built-in skill library that routes your request to the right recipe — and imports packs from the Agents & Skills directory.

F.05

Memory & RAG, offline

Durable notes, session digests and a local project index behind code_search — your code never leaves the machine.

F.06

Permissions you control

Every tool call passes a permission gate. Allow once, allow always, or deny — nothing runs behind your back.
